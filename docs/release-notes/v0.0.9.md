# VoxShift v0.0.9

**The application list keeps itself up to date, and browsers that stayed silent are re-attached automatically.**
Audio routing, the soundboard, VR Controller Mode, settings and the signing setup are otherwise unchanged.

## What's new

### Auto-refresh of the application list
- The list of running applications now refreshes **every 10 seconds** on its own, so a program you start later (or one
  that starts playing) shows up without pressing ⟳ or F5.
- Switch it off in **Preferences → Application list → Auto-refresh every 10 seconds**. It is on by default, also for
  existing users.
- It runs quietly in the background: no loading flicker, the list only changes when something actually changed, and it
  waits while the dropdown is open so entries never move under your cursor.

### Browser audio fix (Brave, Chrome, Edge, …)
- Browsers start their audio helper process only when sound begins and stop it when idle. A capture that was started
  before that helper existed could miss it, so nothing was heard in application mode.
- VoxShift now notices when the captured browser is silent while a new process of the same browser is playing audio, and
  **re-attaches the capture** by itself within a few seconds (at most once every 10 seconds). Silence alone never
  restarts anything, and the event is written to the log.
- If a browser still stays silent: reselect it in the list, check that the tab isn't muted, and attach `VoxShift.log`
  (*Preferences → Open log folder*) to a [bug report](https://github.com/crapclap161/voxshift/issues/new/choose). The
  log shows whether VoxShift tried to re-attach.

## Good to know
- Nothing to migrate: just replace the EXE. Settings, soundboard collections and hotkeys carry over.
- The executable is signed with the VoxShift release key (self-signed, same key as v0.0.8). Windows does not trust a
  self-signed certificate by itself, so SmartScreen can still appear. See the *Digital signature* section below.
- Windows 11 x64 is recommended; application capture works on Windows 10 build 20348 or newer. You still need the free
  [VB-CABLE](https://vb-audio.com/Cable/) driver.
