# VoxShift v0.0.4 — Hear Your Soundboard

A fix release for the soundboard: **you now hear the sounds you play yourself.** In v0.0.3, soundboard sounds were only
sent to VRChat, so other players heard them but you didn't.

## What's new

- 🎧 **Hear sounds myself** (on by default). Every soundboard sound also plays on your **Windows default playback
  device** (your headphones), at the same moment it goes to VRChat.
- 🔊 **Separate volume for you.** The new slider next to *Hear sounds myself* sets how loud you hear the sounds. The
  existing soundboard slider still sets how loud VRChat hears them.
- 🛡️ **Safe by design.**
  - Only the soundboard is played back to you. Your microphone is never echoed into your headphones.
  - VoxShift never monitors into the virtual cable. If your Windows default playback device is CABLE Input, monitoring
    pauses and VoxShift asks you to set your headphones as default, so VRChat never hears sounds twice.
- 🔁 **Follows your devices.** Monitoring moves when you change your Windows default playback device, and it
  recovers after device errors.
- If the virtual microphone isn't running yet, sounds still play in your headphones, and VoxShift tells you that VRChat
  can't hear them.

| Sound goes to | Volume | Contains |
|---|---|---|
| VRChat (virtual microphone) | Soundboard slider | microphone **or** application **+** soundboard |
| Your headphones | *Hear sounds myself* slider | soundboard only |

## Upgrade

Replace the EXE with **`VoxShift-v0.0.4-win-x64-portable.exe`**. All settings and soundboards are kept, and monitoring
is enabled automatically. Verify downloads with `SHA256SUMS.txt`. The EXE isn't code-signed yet, so if SmartScreen
appears, choose **More info → Run anyway**.

## Known limitations

- Monitoring always uses the Windows default playback device. Choosing a different monitor device isn't supported yet.
- Unchanged: OGG/Opus isn't supported, sounds are cut at 5 minutes, application capture works per application (not per
  browser tab), and a virtual audio driver (VB-CABLE) is required.

## Quality

117 unit tests pass (12 new for monitoring). Every release is also smoke-tested on Windows: the real EXE starts,
imports, decodes and plays a WAV file through the soundboard, and performs a real process-loopback capture.
