# VoxShift v0.0.8

**Signed Windows releases and a much easier-to-follow README.** The app itself is unchanged: the same audio routing,
soundboard, VR Controller Mode and settings as v0.0.7.

## What's new

### Signed executable
`VoxShift.exe` is now digitally signed (Authenticode, with a trusted timestamp), so Windows can show who published it.
The portable EXE and the EXE inside the ZIP are the same signed file.

- Check it yourself: right-click the file → **Properties → Digital Signatures**.
- Windows SmartScreen may still show *“Windows protected your PC”* for a new release, because SmartScreen also
  considers how widely a download has been used. If you see it, choose **More info → Run anyway** after checking the
  checksum below.

### A new README for beginners
- Prominent download section, step-by-step Windows installation, and VB-CABLE installation including the reboot.
- A first-time setup walkthrough: microphone, application, virtual cable and the VRChat microphone setting.
- Practical examples (talking, music, talking over music, sounds with automatic microphone muting, VR mode) and a
  clear troubleshooting table.

### Safer release process (for maintainers)
Releases can no longer be published unsigned: the pipeline verifies the signature on the portable EXE and on the EXE
inside the ZIP and the checksums before publishing. See [docs/code-signing.md](https://github.com/crapclap161/voxshift/blob/main/docs/code-signing.md).

## Good to know
- Nothing to migrate: just replace the EXE. Settings, soundboard collections and hotkeys carry over.
- Windows 11 x64 is recommended; application capture works on Windows 10 build 20348 or newer.
- You still need the free [VB-CABLE](https://vb-audio.com/Cable/) driver.
