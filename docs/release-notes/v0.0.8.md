# VoxShift v0.0.8

**Digitally signed releases (self-signed) and a much easier-to-follow README.** The app itself is unchanged: the same
audio routing, soundboard, VR Controller Mode and settings as v0.0.7.

## What's new

### Signed executable (self-signed certificate)
`VoxShift.exe` is now signed with Authenticode (SHA-256, timestamped) using a certificate that belongs to the VoxShift
project. The portable EXE and the EXE inside the ZIP are the same signed file. The signer and key fingerprint are listed in
the *Digital signature* section at the end of these notes.

What this means, honestly:

- ✅ You can confirm the file was **not modified** after signing and that it was signed with the VoxShift release key
  (compare the key fingerprint).
- ❌ The certificate is **self-signed**. Windows does **not** trust it by itself, so VoxShift does **not** appear as a
  verified publisher, and Windows SmartScreen (*“Windows protected your PC”*) **can still appear**. Choose **More info →
  Run anyway** if you downloaded the file from this page.
- Please do **not** install the certificate into your Windows trust store.
- Check it yourself: see [Check your download](https://github.com/crapclap161/voxshift#check-your-download-optional).

### A new README for beginners
- Prominent download section, step-by-step Windows installation, and VB-CABLE installation including the reboot.
- A first-time setup walkthrough: microphone, application, virtual cable and the VRChat microphone setting.
- Practical examples (talking, music, talking over music, sounds with automatic microphone muting, VR mode) and a
  clear troubleshooting table.

### Safer release process (for maintainers)
Releases can no longer be published unsigned: the signing key is kept in GitHub Actions secrets, and the pipeline
verifies the signature on the portable EXE and on the EXE inside the ZIP, and the checksums, before publishing. See [docs/code-signing.md](https://github.com/crapclap161/voxshift/blob/main/docs/code-signing.md).

## Good to know
- Nothing to migrate: just replace the EXE. Settings, soundboard collections and hotkeys carry over.
- Windows 11 x64 is recommended; application capture works on Windows 10 build 20348 or newer.
- You still need the free [VB-CABLE](https://vb-audio.com/Cable/) driver.
