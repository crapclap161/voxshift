# VoxShift v0.0.1 — Initial Release

VoxShift lets you decide with one click what people in VRChat hear: **your microphone** or **the audio of one
application**, such as Spotify, a browser playing YouTube, or VLC. You never have to touch VRChat's audio settings again.

## Highlights

- **Two modes, one click.** 🎤 *Microphone* and 🎵 *Application audio*. Exactly one source is transmitted at a time.
  Switching fades the current source out completely before the next fades in, so the sources never mix and
  switches don't click.
- **Per-application capture.** Only the selected program (and its helper processes) is captured, using the Windows
  process-loopback API. It keeps playing in your own headphones as usual.
- **Independent volumes** from 0–200 % for microphone and application, with a peak limiter that prevents harsh clipping.
- **Live meters** and a clear **ON AIR** indicator showing exactly what VRChat receives.
- **Self-healing.** VoxShift reconnects when a microphone or the virtual cable is unplugged, when Windows default
  devices change, or when the selected app restarts.
- **Comfort features:** global toggle hotkey, Ctrl+1 / Ctrl+2 / F5 shortcuts, tray mode, always-on-top and remembered
  settings.
- **Private by design.** No network access, no telemetry, no administrator rights.

## Requirements

- Windows 11 x64. Application capture also works on Windows 10 build 20348 or newer.
- The free [VB-CABLE](https://vb-audio.com/Cable/) virtual audio driver (installed separately, then reboot).
- No .NET installation needed. The executable is self-contained.

## Getting started

1. Install VB-CABLE and reboot.
2. Download `VoxShift-v0.0.1-win-x64.zip`, extract it and run `VoxShift.exe`.
3. Choose your microphone and the application to share, and set both volumes.
4. In VRChat, set the microphone to **CABLE Output (VB-Audio Virtual Cable)** once.
5. Switch with the two big buttons or the hotkey.

Verify the download with `SHA256SUMS.txt`. The executable isn't code-signed yet, so if SmartScreen appears,
choose **More info → Run anyway**.

## Upgrading from VRChat Audio Switcher

VoxShift is the renamed and refined successor. On first start it imports your previous settings (devices,
application, volumes, hotkey) automatically. You can delete the old program folder afterwards.

## Known limitations

- Capture works per application, **not per browser tab**. Selecting a browser sends all of its tabs.
- DRM-protected playback may be captured as silence.
- A virtual audio driver is required. Windows offers no driver-free way to create a microphone.
- Not yet verified end to end on real hardware by an automated test. The build pipeline runs unit tests and a
  Windows smoke test that includes a real process-loopback capture. Please report any audio issues.
