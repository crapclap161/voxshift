# VoxShift v0.0.2 — Maintenance Release

This is a maintenance release of the build and release pipeline. **The app itself works exactly like v0.0.1.** There
are no feature or behaviour changes, so updating is optional.

## Changes

- **Up-to-date build tooling.** GitHub Actions moved to their current major versions (`actions/checkout` v7,
  `actions/setup-dotnet` v6, `actions/upload-artifact` v7, `softprops/action-gh-release` v3). The Node.js 20
  deprecation warnings in CI are gone.
- **Reproducible build machines.** CI and releases run on pinned runner images (`ubuntu-24.04`, `windows-2025`)
  instead of the moving `-latest` labels.
- **Test tooling.** `xunit.runner.visualstudio` was updated to 4.0.1. All 65 unit tests pass unchanged.
- **Leaner CI previews and fewer update PRs.** Preview builds upload the portable EXE only (half the size), and
  Dependabot bundles GitHub Actions updates into one pull request.

As before, every release build is unit-tested and smoke-tested on Windows before publishing. The smoke test starts
the real executable and performs a real process-loopback capture.

## Download

- **`VoxShift-v0.0.2-win-x64-portable.exe`**: download and run. No installation, no .NET required.
- `VoxShift-v0.0.2-win-x64.zip`: the same EXE plus README, changelog and licenses.
- `SHA256SUMS.txt`: checksums for both files.

Requirements and setup are unchanged: Windows 11 x64 (or Windows 10 build 20348+), plus the free
[VB-CABLE](https://vb-audio.com/Cable/) driver. In VRChat, select **CABLE Output (VB-Audio Virtual Cable)** as your
microphone. The EXE isn't code-signed yet, so if SmartScreen appears, choose **More info → Run anyway**.

## Known limitations

Unchanged from v0.0.1: capture works per application (not per browser tab), DRM-protected playback may be captured
as silence, and a virtual audio driver is required.
